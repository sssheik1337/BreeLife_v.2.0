# Навигация приложения

Этот документ фиксирует единые правила маршрутизации и названий экранов в UI.

## Канонические соответствия экранов и ссылок

- **«Профиль»** = `/resume`
- **«Прогресс»** = `/profile`
- **Старт приложения** = `/profile`
- **«Дневник»** = `/diary`
- **«Рацион»** = `/meal-plan`
- **«Настройки / помощь / тарифы»** = `/menu`

## Правила UI-копирайта

Чтобы не было двойной трактовки, используем единые названия:

1. Кнопки и пункты меню, ведущие на `/resume`, всегда подписываются как **«Профиль»**.
2. Кнопки и пункты меню, ведущие на `/profile`, всегда подписываются как **«Прогресс»**.
3. На экране `/profile` заголовок и подзаголовок должны говорить про прогресс и динамику, а не про «панель» или «профиль».
4. На экране `/resume` тексты кнопок перехода на `/profile` должны явно указывать переход в **прогресс**.

## Чек-лист согласованности при изменениях навигации

Перед слиянием изменений проверьте:

- [ ] Все ссылки на `/resume` в UI подписаны как «Профиль».
- [ ] Все ссылки на `/profile` в UI подписаны как «Прогресс».
- [ ] Подсветка активного пункта в нижнем меню соответствует пути (`/resume` → «Профиль», `/profile` → «Прогресс»).
- [ ] Логотип и стартовый переход ведут на `/profile`.
- [ ] В шапке/меню нет противоречивых названий для тех же маршрутов.
